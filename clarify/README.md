# clarify · 需求澄清器

动手之前系统性收集需求细节，把有歧义、不确定的点全部问清楚，直到需求毫无模糊空间。

## 用途

- **只澄清，不做计划、不做实施**：不给实现方案、不写代码、不跑命令。
- 两层澄清：先挖任务本身特有的**决策分叉**，再用固定维度清单（范围/优先级/约束/验收/影响面/风格/边界异常）兜底查漏。
- 事实类问题自己查代码，决策类问题才抛给用户；每个问题给 2-4 个带权衡说明的选项。
- 主动设想用户没说但会遇到的**边界 case**，一并抛出对齐。
- 澄清完毕后输出需求摘要，并用 AskUserQuestion 让用户选下一步（进入计划模式 / 直接实施）。

## 用法

```
/clarify <任务描述>
```

## 安装

```bash
cp clarify.md ~/.claude/commands/
```
