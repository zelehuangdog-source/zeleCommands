# ultracode · 多智能体编排器

通过多 agent 并行协作完成复杂任务，封装从需求澄清到方案确认到执行的完整流程。

## 用途

三段式流程，严格按顺序、禁止跳步：

1. **Phase 1 · 需求澄清**：调用 `/clarify` 完成需求澄清，输出需求摘要。
2. **Phase 2 · 方案设计 & 用户确认**：设计 Workflow 脚本，讲清整体架构、每个 agent 的输入输出、汇总/评估策略、预期产出，用户确认后才继续。
3. **Phase 3 · 执行**：唯一动作是调用 Workflow 工具执行脚本，禁止自己手动跑任务逻辑；完成后完整呈现结果。

## 用法

```
/ultracode <复杂任务>
```

## 安装

```bash
cp ultracode.md ~/.claude/commands/
```
